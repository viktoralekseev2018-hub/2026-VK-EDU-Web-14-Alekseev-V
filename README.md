# AskSpace — статическая вёрстка, ДЗ 1

Обычные HTML-файлы с Bootstrap. Bootstrap, стили, JavaScript, аватары и favicon находятся локально в `public/static/`.

## Запуск

Откройте `public/index.html` в браузере.

Также можно запустить локальный сервер из корня проекта:

```sh
python -m http.server 8000 --directory public
```

Адрес: http://localhost:8000. Остановка: Ctrl+C.

## Страницы

| Файл | Назначение |
| --- | --- |
| public/base.html | Общий layout: header, main, sidebar и footer |
| public/index.html | Список вопросов и пагинация |
| public/question.html | Один вопрос, ответы, два состояния правильного ответа, пагинация и форма ответа |
| public/ask.html | Форма добавления вопроса |
| public/login.html | Вход с примером общей ошибки |
| public/signup.html | Регистрация с примером ошибки email |
| public/profile.html | Профиль с аватаром и авторизованной шапкой |

Шапка на остальных страницах содержит ссылки входа и регистрации. На узком экране поиск переносится на новую строку, sidebar — под основную колонку. Подвал прижат к низу окна на коротких страницах.

## Состояния и поведение

- Первые три вопроса показывают лайк, нейтральное состояние и дизлайк. Кнопки переключают состояние и счётчик.
- У первого ответа отмечен «Правильный ответ», у второго — нет. Использован обычный checkbox Bootstrap.
- Формы содержат ограничения длины, подсказки и сообщения под полями. Для просмотра ошибок отправьте пустую форму. В регистрации также проверяется совпадение паролей.
- Поиск и фильтр по тегу работают с карточками в HTML. Теги ведут на `index.html?tag=python`. Дополнительные `hot.html` и `tag.html` не нужны для ДЗ 1.
- Пагинация вопросов: `index.html?page=2`; ответов: `question.html?answers=2#answers`.
- Вопросы, ответы и аккаунты не создаются; данные форм и выбранные файлы никуда не отправляются. Состояния не сохраняются после перезагрузки. Ссылки заголовков ведут на один пример страницы вопроса.
- Вся основная вёрстка находится в HTML. `app.js` отвечает только за демонстрационные действия; без JS остаются страницы, карточки и начальные состояния.

## Структура

```text
public/
  base.html
  index.html
  question.html
  ask.html
  login.html
  signup.html
  profile.html
  static/
    css/bootstrap.min.css
    css/style.css
    js/bootstrap.bundle.min.js
    js/app.js
    img/
```

Основное оформление сделано стандартными классами Bootstrap. Собственный CSS задаёт только размеры аватаров, ограничения ширины и перенос поиска.
